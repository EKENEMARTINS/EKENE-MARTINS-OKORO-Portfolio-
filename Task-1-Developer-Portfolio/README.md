## Run locally

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

No build step or package installation is required.

## Deploy — GitHub Pages

1. Go to github.com and sign in as EKENEMARTINS.
2. Click **New repository**, name it `developer-portfolio`, set it to **Public**, then **Create repository**.
3. Upload `index.html`, `404.html`, `README.md`, and the whole `assets` folder to the repository root.
   - `assets/` must contain `styles.css`, `script.js`, `logo-dark.png`, `logo-light.png`, `logo-social.webp`, `profile.jpg`, and your CV PDF when you have it.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Choose `main` and `/ (root)`, then save.
7. Wait 1–2 minutes, then open the published URL shown in Pages settings. It will look like:
   `https://EKENEMARTINS.github.io/developer-portfolio/`

### Netlify — alternative

1. Sign in to Netlify.
2. Choose **Add new site → Deploy manually**.
3. Drag the complete project folder into the deploy area, or connect the GitHub repository.
4. Netlify will publish the static site. Its custom `404.html` is used for not-found routes.

## Accessibility and privacy

The site includes semantic landmarks, keyboard-accessible controls, focus-friendly inputs, a skip link, and reduced-motion handling. Theme and cookie preferences are stored locally in the visitor's browser. No analytics platform or tracking pixel is installed. UTM query parameters are appended to outbound links for referral attribution where supported; this alone does not collect analytics.
